# Contributing

Thanks for your interest in contributing to Copilot Chat Exporter!

## How to Contribute

1. Fork the repo  
2. Create a feature branch  
3. Commit changes  
4. Open a pull request  

## Guidelines

- Keep PRs small  
- Write clear commit messages  
- Add tests where relevant  
- Follow Founder OS formatting conventions  

## Issues

Use the provided issue templates for bug reports and feature requests.
